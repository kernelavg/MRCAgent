Скиллы агентов
свои .md-инструкции, которые видит каждый агент
Как это работает. Скилл — обычный markdown-файл с правилами. Включённые скиллы попадают в промпт каждого агента роя: стиль кода, чем пользоваться, чего не делать. Скилл можно править, выключать (агенты его не видят), удалять и выгружать обратно в .md. Агент может дочитать скилл целиком инструментом skill("имя").

Скиллов пока нет

Создайте первый — например «Стиль кода» или «Как проверять работу». Или импортируйте готовый .md.

Плагины агентов
Плагины и инструкции для вашего роя
Поддерживаются: ZIP плагина Claude Code с skills/, commands/ и .mcp.json; Markdown. Инструкции передаются агентам; серверы из плагинов управляются в разделе MCP. Slash-команды импортируются как инструкции, не как команды интерфейса. Hooks, подагенты, скрипты из архива и переменные путей не запускаются. Совместимость не полная.

Безопасность: плагины устанавливаются выключенными. Включайте только доверенные: MCP может запускать программы и использовать сеть с правами пользователя. Проверьте состав и команды перед включением.

MCP — внешние инструменты

0 — без лимита: ждём столько, сколько отвечает сервер. Свой таймаут можно задать каждому серверу отдельно.
Пока ни одного. Добавьте сервер ниже — или нажмите «Демо-сервер», он идёт в комплекте.
Подключайте только доверенные серверы: они могут выполнять программы и обращаться к сети.
Запускается как процесс, JSON-RPC идёт в stdin/stdout. Нужен npx, uvx, python — любой MCP-сервер.
Сервер сам скажет, какие инструменты у него есть, — они появятся у агентов. Проверка подключения тут же показывает список.
