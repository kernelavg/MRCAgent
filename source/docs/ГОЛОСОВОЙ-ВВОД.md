# Голосовой ввод в MRCAgent

В основном чате нажмите значок микрофона, разрешите доступ к нему в браузере и произнесите запрос на русском языке. Нажмите микрофон повторно для остановки. Распознанный текст остаётся в поле ввода: проверьте и отправьте его кнопкой или Enter. При отправке запись прерывается, поздние результаты игнорируются.

Распознавание зависит от Web Speech API и его реализации в браузере. В настольном WebView2 поддержка не гарантируется; если кнопка недоступна, откройте локальный интерфейс в совместимом Chrome и разрешите доступ к микрофону. Некоторые реализации передают звук внешнему поставщику распознавания и требуют интернет; не диктуйте секреты, если не согласны на это. Реальный микрофон и Windows WebView2 не проверялись.

Оригинальная озвучка голосом Claude не реализована: подтверждённого публичного API этого голоса в Claude API не обнаружено. Автоматической озвучки ответов нет. Документация Anthropic перечисляет текстовый вывод моделей и показывает голосовой пример с отдельным ElevenLabs TTS, а не API голоса из приложения Claude.
