# Голосовой ввод и локальная озвучка в MRCAgent

В чате ПК нажмите микрофон и разрешите его использование. Распознанный текст появится в поле; проверьте его и отправьте самостоятельно. Эта функция использует Web Speech API браузера и может передавать речь поставщику распознавания, требует совместимого браузера и иногда интернета. В Windows WebView2 поддержка не подтверждена; при необходимости откройте локальный интерфейс в Chrome.

Под ответом нажмите «Озвучить» для синтеза Piper голосом Руслан. Повторное нажатие останавливает воспроизведение. Озвучка выполняется на ПК и не отправляет текст в сетевой сервис. Пока ответ формируется, кнопка не появляется. Длинные ответы могут требовать времени и оперативной памяти. Отмена аудио не обязательно немедленно прерывает обработку на сервере. Ошибки API можно прочитать в уведомлении.

Голос — выбранный готовый ru_RU-ruslan-medium Piper, не голос Claude и не модель RVC. Инструкция исходной модели указывает лицензию обучающих данных CC BY-NC-SA 4.0: https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/ruslan/medium/MODEL_CARD . Перед коммерческим использованием и распространением проверьте права и условия модели и датасета; коммерческие права не гарантируются.

## Запуск из исходников
Установите зависимости из requirements.txt и выполните `python download_voice.py`. Скрипт скачивает модель и конфигурацию с Hugging Face, проверяет SHA-256 и сохраняет их в static/voices. Затем перезапустите сервер. Для обычной работы озвучки после установки сеть не требуется. Сборка BAT и Windows Actions выполняют загрузку модели и включают её в приложение.

Озвучку проверили реальным Piper в Linux и через браузер/HTTP. Нативный Windows WebView2, сборка и запуск Windows EXE для этой версии не проверены. Результаты unit и selftest приложены в docs.
